Interceptors let you run custom logic before, after, or on error of any auto-generated endpoint — Prisma model routes, authentication routes, and file upload routes — without replacing the built-in behavior.

<Callout type="warn">
  **Interceptors are the HTTP layer.** Historically they were the main place people put business logic, often alongside `.hooks.ts`. Since `v1.8.0`, business logic belongs in a [Service Override](/docs/core-concepts/components/service-override). Service Hooks was the earlier service-layer attempt; it is now [deprecated](/docs/core-concepts/components/service-hooks) because its TypeScript experience pushed developers away, while Service Override lets you write domain code as plain service methods. Keep interceptors for request/response handling: normalizing payloads, shaping responses, setting headers, logging, and translating errors.
</Callout>

<Callout type="info">
  Interceptors work alongside [Route Hook](/docs/core-concepts/components/route-hooks) for customizing built-in routes (just like `ArkosRouter`) and give a complete experience when interacting with them.
</Callout>

## Why Interceptors?

Arkos auto-generates routes for your Prisma models, authentication, and file uploads. Interceptors let you attach HTTP-level behavior around those endpoints — reshaping what comes in, adjusting what goes out, adding headers, logging requests, and translating errors — without rewriting the built-in handlers.

For business logic tied to a domain operation (defaults, slugs, related writes, notifications), use [Service Override](/docs/core-concepts/components/service-override) instead. It runs on every service call, not just HTTP requests, and keeps that logic in one typed method.

## The Three Hook Types

### Before Interceptors

Run **before** the main operation. Use them to:

- Normalize or transform the incoming request (`req.body`, `req.query`, `req.params`)
- Accept alternate payload shapes and reshape them for the controller
- Attach request-scoped data (correlation ids, timers) for later interceptors
- Enforce HTTP-level rules that don't depend on the domain

```ts
export const beforeCreateOne = [
  async (req, res, next) => {
    // Unwrap a wrapper object the client sends before the controller builds
    // the service arguments.
    if (req.body?.post) req.body = req.body.post;
    res.locals.startedAt = Date.now();
    next();
  },
];
```

### After Interceptors

Run **after** the main operation succeeds. Use them to:

- Access the result via `res.locals.data.data`
- Shape the outgoing payload (strip fields, wrap envelopes)
- Set response headers (caching, timing, pagination links)
- Log successful operations

```ts
export const afterCreateOne = [
  async (req, res, next) => {
    const record = res.locals.data.data;
    res.set("X-Request-Duration", `${Date.now() - res.locals.startedAt}ms`);
    console.log("Created record:", record.id);
    next();
  },
];
```

### OnError Interceptors

Run **when** the main operation fails. Use them to:

- Clean up temporary files created for the request
- Log errors for monitoring
- Translate or enrich errors before they reach the error handler
- Send failure alerts

```ts
export const onCreateOneError = [
  async (err, req, res, next) => {
    if (req.file) await deleteFile(req.file.path);
    console.error(err.message);
    next(err);
  },
];
```

## Prisma Model Interceptors

Intercept any CRUD operation for a Prisma model request — normalize the payload before create, shape the response after update, or clean up files when creation fails.

```ts title="src/modules/post/post.interceptors.ts"
import { normalizeTags, logCreation, cleanupImage } from "@/src/modules/post/post.middlewares";

export const beforeCreateOne = [normalizeTags];
export const afterCreateOne = [logCreation];
export const onCreateOneError = [cleanupImage];
```

```ts title="src/modules/post/post.middlewares.ts"
import { ArkosRequest, ArkosResponse, ArkosNextFunction } from "arkos";

export const normalizeTags = async (
  req: ArkosRequest,
  _res: ArkosResponse,
  next: ArkosNextFunction
) => {
  // Accept "a,b,c" and turn it into an array before the controller calls the service
  if (typeof req.body?.tags === "string")
    req.body.tags = req.body.tags.split(",").map((tag: string) => tag.trim());
  next();
};

export const logCreation = async (
  req: ArkosRequest,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  console.log("Post created:", res.locals.data.data);
  next();
};

export const cleanupImage = async (
  err: any,
  req: ArkosRequest,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  if (req.body.imageUrl) await deleteFile(req.body.imageUrl);
  next(err);
};
```

## How To Access Data In After Interceptors

After a successful operation, the result is available at `res.locals.data.data`:

```ts title="src/modules/post/post.middlewares.ts"
import { ArkosRequest, ArkosResponse, ArkosNextFunction } from "arkos";

export const afterCreateOne = [
  async (req: ArkosRequest, res: ArkosResponse, next: ArkosNextFunction) => {
    // The created/updated record
    const record = res.locals.data.data;

    // For list operations, it's an array
    const records = res.locals.data.data;

    // For bulk operations, metadata is also available
    const { total, results } = res.locals.data;

    next();
  },
];
```

## Authentication Interceptors

Intercept login to count attempts, log auth events, or observe failed logins for security monitoring.

```ts title="src/modules/auth/auth.interceptors.ts"
import { trackLoginAttempt, logSignup, logFailedLogin } from "./auth.middlewares";

export const beforeLogin = [trackLoginAttempt];
export const afterSignup = [logSignup];
export const onLoginError = [logFailedLogin];
```

```ts title="src/modules/auth/auth.middlewares.ts"
import { ArkosRequest, ArkosResponse, ArkosNextFunction } from "arkos";

export const trackLoginAttempt = async (
  req: ArkosRequest,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  await redis.incr(`login:${req.body.email}`);
  next();
};

export const logSignup = async (
  req: ArkosRequest,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  const user = res.locals.data.data;
  console.log("New signup:", user.id);
  next();
};

export const logFailedLogin = async (
  err: any,
  req: ArkosRequest,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  console.error(`Failed login for ${req.body.email}: ${err.message}`);
  next(err);
};
```

## File Upload Interceptors

Intercept file uploads to validate references before delete, log upload activity, or check permissions before serving files.

```ts title="src/modules/file-upload/file-upload.interceptors.ts"
import { checkReferences, logUpload } from "./file-upload.middlewares";

export const beforeDeleteFile = [checkReferences];
export const afterUploadFile = [logUpload];
```

```ts title="src/modules/file-upload/file-upload.middlewares.ts"
import { ArkosRequest, ArkosResponse, ArkosNextFunction } from "arkos";
import { AppError } from "arkos/error-handler";

export const checkReferences = async (
  req: ArkosRequest,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  const { fileName } = req.params;
  if (await db.isReferenced(fileName)) {
    throw new AppError("File still in use", 400);
  }
  next();
};

export const logUpload = async (
  req: ArkosRequest,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  console.log("Uploaded:", res.locals.data.urls);
  next();
};
```

## Passing Data Between Interceptors

Use `res.locals` to pass data between interceptors in the same request:

```ts title="src/modules/post/post.middlewares.ts"
import { ArkosRequest, ArkosResponse, ArkosNextFunction } from "arkos";

export const startTimer = async (
  _req: ArkosRequest,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  res.locals.startedAt = Date.now();
  next();
};

export const reportTiming = async (
  _req: ArkosRequest,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  res.set("X-Response-Time", `${Date.now() - res.locals.startedAt}ms`);
  next();
};
```

```ts title="src/modules/post/post.interceptors.ts"
import { startTimer, reportTiming } from "./post.middlewares";

export const beforeUpdateOne = [startTimer];
export const afterUpdateOne = [reportTiming];
```

## Type Safety

Use `ArkosRequest` and `ArkosResponse` generics for fully typed interceptors:

```ts title="src/modules/post/post.middlewares.ts"
import { ArkosRequest, ArkosResponse, ArkosNextFunction } from "arkos";
import { Prisma } from "@prisma/client";
import { ArkosPrismaInput } from "arkos/prisma";

type CreatePostBody = ArkosPrismaInput<Prisma.PostCreateInput>;

export const addDefaults = async (
  req: ArkosRequest<any, any, CreatePostBody>,
  res: ArkosResponse,
  next: ArkosNextFunction
) => {
  if (!req.body.publishedAt) {
    req.body.publishedAt = new Date();
  }
  next();
};
```
